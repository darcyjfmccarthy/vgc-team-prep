# Visual asset provenance

Pokémon and held-item sprites are loaded at runtime from the [Pokémon Showdown
sprite host](https://play.pokemonshowdown.com/sprites/) through a narrowly scoped
application provider. No third-party artwork is copied into this repository.

The [Smogon sprite repository](https://github.com/smogon/sprites) states that
its code is MIT-licensed, while the sprites themselves remain the property of
Nintendo, Game Freak, and The Pokémon Company. Some later-generation sprites
were made by community artists and do not currently have a settled reuse
license.

This integration is intended for private, non-commercial use. Permission or
replacement artwork must be reviewed before any public or commercial release.
